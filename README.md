# 联沃智坊新一代 ERP / MES 一体化系统

**AI 驱动业务协同，打通业财与车间现场。**

联沃智坊新一代 ERP / MES 一体化系统（FangERP）是面向消费电子与离散制造业的 AI 驱动型一体化管理系统，连接销售、采购、库存、生产、质量和财务，将企业经营管理与车间制造执行放到统一的业务链路中。

FangERP 以 AI 驱动业务理解与岗位协同，结合现场操作引导和企业知识，帮助员工用更自然的方式理解业务、获取信息和完成工作，降低 ERP 的学习与使用成本。MCP 与 Agent Skills 为 AI 连接业务工具与岗位知识提供标准化方式，让 AI 更贴近企业日常工作。

[English](README.en.md) · [产品总览](docs/product-overview.md) · [产品功能与实施服务](docs/product-capabilities.md)

## FangERP 关注的制造业问题

- **业务与财务衔接**。销售、采购、收付款、库存和生产业务关联财务记录，支持从业务单据联查凭证。
- **生产现场透明**。通过工单、派工任务、扫码过站和完工报数，记录产品做到了哪道工序、产生了多少良品和不良。
- **产品质量可追溯**。关联物料批次、生产批次、SN 序列号、工站和不良处置记录。
- **岗位操作更清楚**。现场端围绕当前任务提供下一步引导、工序用料与电子作业指导书，帮助员工完成当下工作。
- **AI 驱动岗位协同**。围绕业务理解、信息获取和操作引导组织 AI 应用，将企业知识与岗位任务联系起来。

## 产品能力

| 方向 | 业务内容 | 应用价值 |
| --- | --- | --- |
| ERP 与业财一体化 | 销售、采购、库存、BOM、生产计划、收付款、会计管理 | 连接订单、物料、生产和财务 |
| MES 制造执行 | 派工报工、批次流转、SN 过站、工站上料、完工入库 | 掌握工序进度与现场产出 |
| 质量与追溯 | 不良登记与判定、返工报废、物料批次追溯、生产报表 | 关联产品履历与质量处置 |
| 财务管理 | 会计准则科目表、凭证号、凭证查询、源单据联查 | 让财务记录与业务单据相互关联 |
| AI 与岗位协同 | 业务理解、岗位引导与企业知识协同 | 降低学习成本，让 AI 更贴近日常业务 |

## 适用场景

重点面向消费电子、显示模组、电子装配等离散制造场景，适合需要同时梳理订单、物料、车间过程、质量记录和财务衔接的企业。

企业可以从 MES 现场管理起步，逐步拓展订单、采购、库存与财务的协同范围，也可以开展 ERP + MES 一体化建设。实施内容结合企业现状确定。

## 交付与实施

联沃智坊为制造企业提供稳定的系统交付与实施服务，结合企业工艺流程、岗位分工和部署要求组织项目实施，支持 MES 现场管理和 ERP + MES 一体化建设。
