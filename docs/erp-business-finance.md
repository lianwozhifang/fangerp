# 联沃智坊新一代 ERP / MES 一体化系统的业财一体化

联沃智坊新一代 ERP / MES 一体化系统（FangERP）连接销售、采购、库存、生产和财务，帮助制造企业沿同一条单据链路理解订单履行、库存变化和财务记录，让业务岗位与财务人员能够围绕关联单据开展协作。

## 业财一体化如何体现在日常工作中

销售、采购、仓储和生产活动形成业务单据，符合会计条件的业务按系统规则生成关联会计记录。财务人员能够追溯记录所依据的业务，业务人员能够按权限查看相关单据的处理结果。

FangERP 提供凭证编号、凭证查询及源单据联查，将业务单据与财务记录衔接起来。

## 订单与供应链

| 业务环节 | 典型内容 | 关联价值 |
| --- | --- | --- |
| 销售 | 客户、报价、销售订单、交付与销售发票 | 连接需求、交付、应收和收款 |
| 采购 | 供应商、物料需求、采购订单、采购入库与采购发票 | 连接采购、收料、应付和付款 |
| 库存 | 仓库、批号、序列号、物料收发与盘点 | 保留物料数量和流向记录 |
| 生产 | BOM、工艺路线、生产计划、物料需求计划与工单 | 将订单需求落实到制造任务 |
| 财务 | 会计科目、总账、往来与收付款 | 将经营业务与会计记录关联 |

上述业务在联沃智坊新一代 ERP / MES 一体化系统中相互关联，企业可以按岗位职责和业务流程配置使用。

## ERP 与 MES 如何衔接

ERP 提供物料、BOM、工单和库存等基础，MES 记录工序执行、批次流转、SN 过站和质量结果。

FangERP 将现场产出与工单关联，并通过完工入库流程衔接库存。相关用料与损耗按业务规则进入对应的生产和库存记录，便于进一步核对数量、物料消耗与财务依据。

这种衔接让计划、生产、仓储和财务能够围绕关联单据开展协作。

## 财务管理与凭证联查

- 会计准则与科目表管理。
- 按财务岗位组织的菜单与操作入口。
- 业务过账时的凭证编号。
- 凭证汇总、借贷分录展开和条件查询。
- 凭证与销售、采购、收付款、库存等源单据的双向联查。

更多业务功能与交付说明见产品功能与实施服务文档。[产品功能与实施服务](product-capabilities.md)

## 从订单到财务的业务协同

企业可以沿相互关联的业务单据查看订单、生产、入库与财务记录。

1. 销售订单提出产品需求。
2. 生产计划和物料需求支持采购与工单安排。
3. MES 记录工序进度、完工数量和质量结果。
4. 完工入库形成库存业务记录。
5. 在有权查看的业务单据和凭证之间联查。

各岗位可以按权限沿单据链路联查，核对订单履行、生产结果、库存变化与财务记录。
