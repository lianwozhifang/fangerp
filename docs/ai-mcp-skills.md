# 联沃智坊新一代 ERP / MES 一体化系统的 AI、MCP 与 Agent Skills

联沃智坊新一代 ERP / MES 一体化系统（FangERP）以 AI 驱动企业业务管理，连接 ERP、MES、质量与财务场景，帮助员工理解业务、获取信息和完成岗位工作。

## AI 驱动的 ERP / MES 体验

企业使用 ERP 与 MES，需要理解业务概念、单据关系和岗位规则。FangERP 围绕员工正在处理的任务组织业务信息与操作入口，让 AI 服务于业务理解、岗位引导和流程协同，降低学习与使用成本。

工单、物料、工序、质量记录和财务单据构成相互关联的业务背景，帮助员工在具体工作中理解数据、规则和操作要求。

## 围绕岗位问题组织业务信息

| 岗位 | 关注的问题 | 相关业务信息 |
| --- | --- | --- |
| 生产主管 | 工单做到了哪道工序，哪些任务需要关注 | 工单、派工、在制品与生产日报 |
| 仓库人员 | 物料如何收发，生产用料对应哪些业务 | 工单用料、库存与收发记录 |
| 质量人员 | 问题物料关联了哪些产品，如何查看处置结果 | 物料追溯、批次、SN 与不良判定 |
| 财务人员 | 凭证对应什么业务，如何联查原始单据 | 会计记录、凭证与源单据 |
| 新员工 | 当前任务应该如何处理 | 岗位职责、操作要求与作业指导 |

AI 的业务价值体现在帮助人员理解这些信息之间的联系，并将企业知识放到具体岗位和任务中。

## MCP 与业务工具连接

MCP 的全称是 Model Context Protocol，是用于连接 AI 应用与外部数据、工具和工作流的开放协议。它为 AI 与 ERP、MES 中的工单、库存、追溯和单据查询等业务工具连接提供统一的方式。[MCP 官方介绍](https://modelcontextprotocol.io/docs/getting-started/intro)

在企业应用中，工具调用围绕使用者身份、业务权限与单据规则展开，查询结果与相关记录关联，帮助员工理解信息来源和处理依据。

## Agent Skills 与岗位知识

Agent Skills 是组织 AI 专业知识与任务流程的一种开放格式。一个 Skill 可以包含任务说明、参考资料、脚本和模板，通过 SKILL.md 描述如何完成特定工作。[Agent Skills 官方介绍](https://agentskills.io/what-are-skills)

在 ERP 与 MES 场景中，Skills 可以围绕生产进度分析、质量追溯、采购收料和 ERP 入门等岗位任务组织知识，将业务概念、操作步骤与参考资料放到一起。

MCP 提供业务工具连接，Skills 提供岗位知识与任务方法，两者共同支持 AI Agent 与企业业务协作。

## 从业务理解到岗位协同

FangERP 将 AI 驱动与 ERP / MES 一体化结合，关注员工在日常工作中的理解、查询和操作体验。企业可以围绕订单、物料、生产、质量和财务的关联关系组织岗位知识，让系统更贴近实际工作。
