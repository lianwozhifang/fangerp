# 联沃智坊新一代 ERP / MES 一体化系统产品功能与实施服务

联沃智坊新一代 ERP / MES 一体化系统（FangERP）为消费电子与离散制造企业提供 ERP 业务管理、MES 制造执行、质量追溯和财务协同，并提供稳定的系统交付与实施服务。

## ERP 与财务管理

| 能力 | 业务内容 | 应用价值 |
| --- | --- | --- |
| 销售与采购 | 客户、供应商、订单、收发货与往来业务 | 关联需求、供应与交付 |
| 库存管理 | 仓库、批号、序列号、收发料与盘点 | 记录物料数量与流向 |
| 生产管理 | BOM、生产计划、物料需求计划与工单 | 将订单需求落实到制造任务 |
| 岗位操作与单据联查 | 业务菜单、岗位权限和关联单据查询 | 帮助员工按职责处理工作 |
| 会计准则与科目表 | 财务基础资料与科目管理 | 统一会计记录依据 |
| 凭证编号与查询 | 凭证号、分录展开和条件查询 | 便于查看与核对会计记录 |
| 业务与财务联查 | 凭证与销售、采购、收付款和库存单据关联 | 沿业务链路追溯财务依据 |

## MES 制造执行

| 能力 | 业务内容 | 应用价值 |
| --- | --- | --- |
| 派工报工 | 工单下达、工序任务与现场报数 | 连接计划安排与现场产出 |
| 产品跟踪 | 按批、按件和先批后件跟踪 | 适应不同产品与工艺 |
| 工序流转 | 工艺路线、进出站与工站匹配校验 | 保留制造过程履历 |
| 上料与追溯 | 工站上料、物料批次与生产对象关联 | 查询物料来源与关联产品 |
| 质量处置 | 不良登记、待判、返工、放行与报废 | 记录质量问题与处理结果 |
| 工序数据采集 | 采集模板、规格要求与采集记录 | 关联工序数据和生产对象 |
| 现场作业指导 | 下一步引导与电子作业指导书 | 帮助人员完成当前任务 |
| 完工入库 | 生产结果与关联入库任务衔接 | 连接现场执行与库存 |
| 生产报表 | 产出、良率、在制品、不良、用料和人员相关报表 | 支持日常管理与业务分析 |

## 交付与实施服务

FangERP 提供 SaaS 与私有化部署方案。实施围绕企业工艺流程、岗位职责、资料管理和运行环境组织，支持从 MES 现场管理起步，也支持 ERP + MES 一体化建设。

企业可根据业务目标明确使用范围、岗位配置、接口需求和上线安排，将系统应用到订单、物料、生产、质量与财务协作中。
