# 联沃智坊新一代 ERP / MES 一体化系统的制造执行与质量追溯

联沃智坊新一代 ERP / MES 一体化系统（FangERP）面向离散制造现场，围绕工单、工艺路线、工站、生产批次和 SN 序列号记录制造过程，并与 ERP 的物料、库存和完工入库业务衔接。系统支持批次流转、SN 过站、上料记录、不良处置和多类生产报表。

## 从工单到现场执行

工单确定产品、计划数量和工艺要求，派工任务关联具体作业。现场人员扫码获取生产对象，在匹配的工站进站和完工报数，系统据此记录工序进度与生产结果。

系统根据工艺路线与工站配置进行顺序和工站匹配校验，帮助减少漏站、错站等操作问题。

## 三种生产跟踪方式

| 跟踪方式 | 适用过程 | 记录重点 |
| --- | --- | --- |
| 按批跟踪 | 多件产品共同经历相同工序 | 批次数量、工序经历、拆批和质量结果 |
| 按件跟踪 | 每件产品有独立序列号 | SN 履历、过站、关键件绑定和维修记录 |
| 先批后件 | 前段批量加工，后段逐件赋码 | 来源批次与后续 SN 之间的关联 |

生产批次中的产品发生不同经历时，通过拆批保留各自的工序与质量记录。具体跟踪方式结合产品和工艺配置。

## 工站上料与用料追溯

工站上料记录物料、批号或供应商批号、操作人员和时间等信息。关联工单时，系统按工单用料进行上料校验。

产品或生产批次经过工站时，系统关联适用的上料记录，形成后续追溯依据。

- 从生产批次或 SN 查询相关物料批次。
- 从物料批次查询关联的生产批次和 SN。
- 沿拆批关系查看批次来源与流向。
- 关联完工后的库存批号或成品序列号。

追溯结果用于定位需要核查的影响范围。批量上料场景中的物料关联按工站与过站记录建立，具体范围结合现场换料和批次管理方式确认。

## 不良登记与质量判定

现场完工报数可以登记不良代码和数量，不良进入待判流程。具备相应权限的人员进一步判定返工、放行或报废。

系统保留发现工序、生产对象、数量、处置结果和操作记录，并区分不良、待判、返工和报废等统计含义。

按件生产同时支持不良下线与维修记录，便于查看单件产品的处理经过。

## 数据采集与作业指导

采集模板用于定义工序需要记录的数据项及规格要求，采集结果与制造过程关联。电子作业指导书按工序和物料提供给现场人员。

现场端通过当前状态、下一步提示和任务按钮组织操作，帮助人员理解当前批次或 SN 应当如何处理。

## 生产报表

| 报表 | 常见管理问题 |
| --- | --- |
| 生产日报 | 各工序、工站或班次完成了多少产出 |
| 工单良率 | 工单有哪些良品、不良与待判数量 |
| 不良分析 | 主要不良集中在哪些工序和原因 |
| 在制品 | 哪些批次或 SN 正在加工、等待或异常处理中 |
| 直通率分析 | 各工序一次通过情况如何 |
| 用料差异 | 理论用料与实际消耗有哪些差异 |
| 人员产出与在岗工时 | 人员参与了哪些生产任务、记录了多少在岗时间 |

这些报表基于系统记录的业务数据统计。企业实施时需要明确扫码、报数、换料与质量处置的现场规范。

## 与 ERP 的完工衔接

末道工序完成后，系统按业务条件触发完工入库任务，将生产结果衔接到 ERP 库存。生产经理、仓管和财务人员可围绕关联的工单与入库单进一步核对。
